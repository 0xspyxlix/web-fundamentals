Using Contextual Selectors

This checkpoint builds on the first one by adding contextual selectors to the stylesheet. Instead of styling every link or every h2 the same way, contextual selectors let me target elements based on where they are in the HTML. So the hover color on nav links only kicks in for anchors that are inside the nav inside the header, and the green heading style only hits h2 tags that sit inside an article element.

Why Contextual Selectors Are Useful

Without them I would need to add a class to every element I want to style differently. Contextual selectors use the page structure to figure out which rule applies where, so the HTML stays cleaner. The header nav a:hover rule means "when someone hovers over a link inside the nav inside the header, turn it teal." And article h2 means "any h2 that is inside an article gets the green color and bottom border." Hover over the nav links above to see the teal color.
