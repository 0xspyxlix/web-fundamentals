Checkpoint 1: External Style Sheet

This page is linked to an external style sheet called checkpoint1.css. All the styling you see here comes from that one file. The body has a background color, a text color, and a font-family set through CSS instead of using HTML attributes. If I change something in the CSS file and reload this page, the new styles show up automatically without touching the HTML at all.

Why External Style Sheets Matter

The main benefit is that you can control the look of multiple pages from a single file. If this site had ten pages all linking to the same stylesheet, changing the background color in one place would update all ten pages at once. That saves a ton of time compared to editing inline styles on every single page.

CSS Properties Used on This Page

  • background-color sets the background of the page
  • color sets the text color for the body
  • font-family picks which font the browser uses
  • font-size controls how big or small the text is
