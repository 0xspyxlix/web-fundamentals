Getting Started with External CSS

For this checkpoint I set up an external stylesheet and linked it to my travel blog page. The stylesheet has one rule targeting the body element which controls the background color, font, line height, and text color for the whole page. All the styling comes from that single CSS file instead of being written inline on each element.

What the Stylesheet Does

The background is set to a light gray (#f9f9f9) which is easier on the eyes than pure white. The font is Arial with sans-serif as a fallback. Line height is 1.6 so there is enough space between lines of text to read comfortably, and the text color is a dark gray (#333333) instead of full black.

The nice thing about having this in an external file is that if I add more pages to the blog later I can link the same stylesheet to all of them and they will look consistent without me having to copy paste styles everywhere.
