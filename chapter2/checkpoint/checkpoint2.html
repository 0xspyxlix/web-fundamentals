Chapter 2 - Checkpoint 2

Textbook Checkpoint 2.2, covering special characters and hyperlinks.

1. Describe the purpose of special characters in HTML.

Special characters, also called character entities, are codes used to display characters that are either reserved in HTML or not available on a standard keyboard. Because characters like <, >, and & have special meaning in HTML, they must be written as entity references (&lt;, &gt;, &amp;) when you want them to appear as visible text. Entity references are also used for symbols such as the copyright sign (&copy; displays ©) and non-breaking spaces (&nbsp;). Every entity begins with an ampersand and ends with a semicolon.

2. When would you use an absolute link? Does it use the http protocol?

An absolute link (absolute URL) is used when you need to link to a resource on a different website or a different web server. It includes the complete address: the protocol (such as https://), the domain name, and the path to the specific page or file. Yes, an absolute link uses the http or https protocol as part of the full URL. For example: https://www.w3.org/.

3. When would you use a relative link? Does it use the http protocol?

A relative link is used when linking to another page or file within the same website. It specifies the path from the current document to the target file without including the protocol or domain name. No, a relative link does not use the http protocol because it references files relative to the current location on the same server. For example, contact.html or ../images/photo.jpg.
