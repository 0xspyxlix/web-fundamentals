Chapter 2 - Checkpoint 2

Answers for Checkpoint 2.2 from the textbook.

1. Describe the purpose of special characters in HTML.

Some characters already mean something in HTML, like < and > which the browser reads as the start and end of tags. So if you actually want to display those characters on the page as text, you have to use special codes called character entities. For example, &lt; shows a less-than sign and &amp; shows an ampersand. They're also useful for symbols you can't easily type on a keyboard, like &copy; for the copyright symbol (©). Every entity starts with & and ends with a semicolon.

2. When would you use an absolute link? Does it use the http protocol?

You use an absolute link when you're linking to a page on a completely different website. It has the full address including the protocol, domain, and path - like https://www.google.com. So yes, it does use http (or more commonly https these days). Basically, if the page you're linking to isn't on the same server as your site, you need the whole URL.

3. When would you use a relative link? Does it use the http protocol?

A relative link is what you use when linking to another page on your own site. Instead of writing out the full URL, you just write the path from where you are to where you want to go. Something like about.html if it's in the same folder, or ../images/pic.jpg if you need to go up a folder first. It doesn't use http at all since the browser already knows what server it's on - it just needs the file path.
