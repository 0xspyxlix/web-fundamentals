Chapter 2 - Checkpoint 1

Answers for Checkpoint 2.1 from the textbook.

1. Describe the features of the heading element.

There are six heading levels in HTML, going from <h1> down to <h6>. The h1 is the biggest and most important one, and h6 is the smallest. Each heading shows up on its own line with some space around it, so they naturally break up the page into sections. You're supposed to use them in order too - like h1 for the main title, h2 for sub-sections, h3 under those, and so on. Screen readers and search engines also use headings to figure out what the page is about, so getting the order right matters for accessibility.

2. What is the difference between an ordered list and an unordered list?

An ordered list uses the <ol> tag and shows items with numbers (1, 2, 3, etc.). You'd use it when the order actually matters, like steps in a recipe or a ranking. An unordered list uses <ul> and shows bullet points instead. That one is for when you just have a group of items and it doesn't matter which comes first. Both types wrap each item in <li> tags.

3. Describe the purpose of the blockquote element.

The <blockquote> element is for when you want to include a longer quote from somewhere else, like another website or a book. The browser automatically indents it so it stands out from the rest of the text. It's different from just putting quote marks around something inline - blockquote is meant for bigger chunks of quoted text that you want to separate from your own writing.
