Chapter 2 - Checkpoint 1

Textbook Checkpoint 2.1, covering headings, lists, and the blockquote element.

1. Describe the features of the heading element.

HTML provides six levels of heading elements, from <h1> (the largest and most important) through <h6> (the smallest and least important). Headings are block-level elements, meaning each one displays on its own line with space above and below it. They create a document outline that organizes content into sections. Search engines and screen readers rely on headings to understand page structure, so using them in the correct order (h1 first, then h2 for subsections, and so on) is important for both accessibility and SEO.

2. What is the difference between an ordered list and an unordered list?

An ordered list (<ol>) displays items with sequential numbers or letters, which indicates that the items follow a specific sequence or ranking. An unordered list (<ul>) displays items with bullet points, which indicates a collection of related items where the order does not matter. Both list types use the <li> element to mark up each individual item.

3. Describe the purpose of the blockquote element.

The <blockquote> element is used to indicate a section of text that is a quotation from another source. Browsers typically render blockquote content as indented from the left and right margins, visually setting it apart from the surrounding text. It is meant for longer quotations that deserve their own block rather than being placed inline within a paragraph.
